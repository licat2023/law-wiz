# 合同审查双栏界面

## 用户需求依据

- R1，本次聊天原文节选：“左侧是上传的文档，最上面有个上传文档的按钮，当拖动文件时提示可以拖入界面内（范围为整个‘合同智能审查’界面，除了导航栏）。”
- R2，同一请求原文：“右侧显示文档风险报告或是分析进度。打开时默认引导用户上传文档或在左侧查看任务（如果有的话显示这句）”
- R3，同一请求的附件。截图展示原有单栏上传页，作为改造前的界面参考。

## 当前任务理解

用同一界面管理文档上传、任务选择、进度和报告。默认打开审查首页时不自动选择任务。有任务才出现查看任务的引导。保持已有报告链接、个人中心入口、风险追问、误报标记和 PDF 下载。

实施选择：选中或拖入一个有效文件后直接上传并发起审查，用现有的审查历史接口按任务展示文档并支持翻页。窄屏下把文档列表放在内容上方。

## 实施方案

1. 记录旧版布局，复用现有上传、任务列表和报告接口。
2. 建立文档列表及右侧内容区，处理整个审查区域的文件拖放、上传进度与提交重试。
3. 复用审查详情进度和报告，保留原路由并验证历史入口、任务切换和失败状态。
4. 用浏览器覆盖交互与布局，再从 Git 归档执行前端检查。
