# 法律助手答复与正文脚注

## 用户需求依据

- R1，本次聊天。用户要求“不用要求Agent给出法律结论，而是要他作为用户的法律助手，可以提示用户能使用Agent做什么”。
- R2，本次聊天。用户明确说“‘本轮未找到直接法律依据。’不需要”，并要求法律条文像论文引用脚注一样标在正文中。附图展示了「你好」触发旧提示和问卷式回复的情形。

## 当前任务理解

普通问答和报告追问采用法律助手的语气。问候或能力询问得到简短介绍，具体问题得到通俗解释、事实核对或下一步。保留法条溯源，避免编造依据。不再生成或显示固定的无依据提示。正文上标对应实际引用，点击展开并定位该条法条原文。已有会话中的固定前缀在显示时去除，保留已有正文和可核对的引用快照。

实施选择：沿用正文 `[编号]` 与 `citations` 契约。保存时仅保留既出现在正文又通过候选校验的引用，按首次出现顺序编号。流式预览暂不展示脚注，正式回答到达后显示。

## 实施方案

1. 调整普通和报告模式的提示词，去除 AI 服务自动追加的固定提示，测试真实引用与编号校验。
2. 为完成的助手消息渲染可点击脚注，处理旧答复固定前缀、报告原文中的历史编号和空白对话引导。
3. 从干净源码构建并检查，实测问候、流式回答和脚注交互，校对业务文档。
