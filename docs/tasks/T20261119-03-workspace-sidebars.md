# 统一业务侧栏与移除重复审查记录

## 用户需求依据

- 本次聊天原文：“个人中心删除合同审查记录卡片”。
- 同一请求原文：“‘合同审查’与‘法律问答’左侧侧边栏统一宽度、样式”。
- 同一请求要求悬停和选中的条目使用同一种灰色背景，悬停一段时间后向左滚动标题，直到文字末尾与归档图标盒子的左边缘对齐。

## 当前任务理解

移除个人中心的审查记录卡片及其独立请求。合同审查和法律问答复用侧栏布局、按钮、行距及条目样式。桌面宽度统一为 280 像素，窄屏时侧栏在主内容上方。超出归档操作区的标题悬停 500 毫秒后向左滚动一次，移出时复位。键盘焦点可以预览长标题，减少动态效果时直接显示末尾。

## 实施方案

1. 用共用侧栏和条目组件替换两页各自的布局和行样式。
2. 使用与归档组件相同的尺寸计算标题可视宽度，增加延迟、滚动和复位。
3. 删除个人中心的重复展示与请求，从 Git 归档构建并在浏览器验证。

## 验证结果与未解决事项

- Git 归档中的锁定依赖安装、lint、改动文件格式检查、类型检查和生产构建均通过。本机开发前端已更新。
- 浏览器测得两页桌面侧栏同为 280 像素，侧栏起点和顶部操作区高度一致。390 像素宽窗口下，侧栏和主内容均以 366 像素宽上下排列。
- 用测试条目核对悬停与选中背景一致、滚动延迟为 500 毫秒、标题末尾与归档区边缘在一个像素内对齐、离开后归零及短标题静止。键盘焦点可以预览，开启减少动态效果时延迟结束后立即显示标题末尾。
- 浏览器检查确认个人中心只请求归档列表，账号信息和两类归档仍可访问。使用模拟会话确认新侧栏中的归档按钮仍能操作。
