# 法律问答报告选择与个人中心精简

## 用户需求依据

- R1，本次聊天的法律问答截图。红色批注 “默认不要这些，默认这个Agent是回答用户法律疑问的” 指向展开的开发样本引用，并要求“添加一个选择报告的展开下拉列表”。
- R2，本次聊天的个人中心截图。红色批注 “删了” 指向脱敏提示，“暂时不用这些” 框选机构资料。

## 当前任务理解

法律问答页默认可直接输入法律问题。报告是可选上下文，来源为当前账号已完成的合同审查，使用现有报告追问会话。回答正文优先展示，依据可展开。开发替身不可将检索命中包装为实际答案或引用。个人中心去掉脱敏提示和机构资料卡片，保留账号信息及合同审查记录。

实施选择：从导航打开问答时用空白草稿。发送时创建所选上下文的会话。已有会话的上下文确定后保持固定，切换或清除报告时在发送后开启对应的新会话。依据继续遵循现有法条溯源规则。

## 实施方案

1. 复现开发替身返回模板和全部命中的问题，加入针对性回归。真实模型直接回答当前问题，只保存实际使用的候选编号，沿用报告追问的校验。
2. 在问答输入区复用已完成审查列表和会话接口。整份报告追问携带摘要和最多八条未标为误报的风险简述及建议。校验空列表、切换、报告追问入口及旧会话。个人中心卡片使用现有页面宽度。
3. 从干净源码验证前端构建和 AI 测试，在本机开发环境检查页面和接口。
