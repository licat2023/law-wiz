# 法律问答归档管理

## 用户需求依据

- 本次聊天原文：“对法律问答处的归档也做类似处理”。
- 所指交互见 [审查文档归档管理](T20261119-01-review-archive.md)，包括悬停显示归档图标、归档通知、绿色还原图标和彻底删除确认。

## 当前任务理解

法律问答列表仅展示活跃会话。个人中心的归档管理按审查文档和问答会话切换，已有归档会话可还原或彻底删除。还原保留原有消息与引用。彻底删除须确认，仅本人已归档且没有正在生成回答的会话可删除，清理消息、引用及会话本身。

## 实施方案

1. 沿用现有归档路由和状态，增加还原与彻底删除接口。
2. 复用归档操作图标，增加问答列表悬停入口和个人中心归档分类。
3. 从 Git 归档构建，并验证存量归档、颜色、确认、授权与消息清理。
