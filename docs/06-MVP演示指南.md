# 智法宝 Demo 演示指南

## 准备环境

按 [部署说明](../deploy/README.md#本地-demo) 用 Compose 初始化空库并启动全栈。在知识库管理后台创建库，上传文件或新建 Markdown。配置业务 reader 和默认库 ID，等待文档索引完成并抽查一条检索结果。

开发 Compose 默认使用开发嵌入和模型替身。真实演示在 `.env.dev` 配置远程模型和嵌入服务。

## 合同审查

1. 注册并登录业务前端。
2. 上传含正文的 PDF、DOCX 或 TXT，提交审查并查看进度。
3. 在结果页逐条核对合同原文、风险说明和法条，下载 PDF，确认原文位于对应风险说明上方。
4. 上传扫描件或损坏文件，核对系统给出的失败原因。

合同正文由业务后端提取并保存到合同版本。独立 AI 服务运行审查 Agent 并检索法条，合同原件和报告存入 RustFS。离线模型替身展示任务和报告链路，风险规则为空时报告可无风险点。

可以上传[虚构采购合同](tasks/T20261118-05-review-clause-excerpts/purchase-contract.txt)验证风险原文。要一起验证法条引用，把《民法典》买卖合同的相关条文加入审查使用的默认库并等待索引就绪。样本的两小时验收与四十八小时运行测试适合核对第六百二十二条，付款期限空白可用第六百二十八条核对。[国家市场监督管理总局发布的《中华人民共和国民法典》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_60fb3863b7364b759123a42d1df568ca.html)

## 法律问答

1. 打开法律问答，发送「你好」查看助手能提供的帮助，再提一个与已索引语料匹配的问题。使用真实生成模型时，观察答复逐段出现，生成结束后点击正文上标查看对应法条和原文。
2. 在输入区展开「选择审查报告（可选）」，选择已完成的报告并针对报告中的风险提问。核对实际引用的报告发现及对话顶部的报告链接。切换或清除关联报告后发送会开启另一段对话。
3. 在一条回答生成时刷新页面，确认会话可继续展示回答。重新打开历史会话，确认已保存的回答和引用可查看。开发替身可用于验证会话和报告上下文流程，普通问答会提示模型暂不可用。

## 知识库

管理后台可以查看文档、索引任务和检索块。文档有变更时创建新修订，新索引完成后成为检索版本。处理失败时，可查看失败原因并继续查询旧生效索引。
